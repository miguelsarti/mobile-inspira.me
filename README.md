# Inspira.me
Projeto avaliativo de um aplicativo de citações chamado "Inspira.me". Ele conta com uma página inicial, de listagem, criação e perfil.

## Instalação
```bash
git clone https://github.com/miguelsarti/mobile-inspira.me
cd Inspira.me
npm i
```

## Como rodar
- Front-end:
```bash
npx expo start
```

- Back-end: abra o projeto do back-end e rode:
```bash
npm run dev
```

## Acessar
http://localhost:8081
